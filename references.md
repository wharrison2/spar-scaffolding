# References for code and methods taken from outside this project

- EleutherAI, concept-erasure (LEACE, Belrose et al. 2023, "LEACE: Perfect linear concept erasure in closed form", arXiv:2306.03819). https://github.com/EleutherAI/concept-erasure, MIT licence. Used as a dependency (`pip install concept-erasure`, imported, not copied) by `scripts/persona_vector_projection/fit_leace_eraser_and_effective_facet_directions.py` for the LEACE sensitivity check of the persona vectors. Version tested: 0.2.4.
- `scripts/persona_vector_projection/content_controlled_facet_positive_control_statistics.py` (formerly `moralizing_delivery_positive_control_statistics.py`, kept as an alias) (`attach_rewrite_tokens_to_comparison_units`, `whole_document_shift_with_block_bootstrap`) adapts `per_rewrite_whole_document_block_bootstrap.py`, an analysis script written earlier for this project in a Claude Code session scratchpad (`/private/tmp/claude-501/-Users-williamharrison-Desktop-emergent-alignment/d2297338-9c94-402c-ad84-d8ed6c009f8e/scratchpad/`, outside the repository): the unit definition (every source token a unit, rewrite tokens attached by difflib opcodes) and the moving-block bootstrap, vectorised and generalised to several vectors.
- `scripts/persona_vector_projection/collect_difficult_advice_dataset_answers_for_persona_vector_scoring.py` re-implements (not imports) three small pieces of `dad-model-experiment-2026-11-01/code/judge.py`, the judging script of the difficult-advice model-per-stage experiment (placed in this repository as read-only input, written outside it): `key_of` (md5 of the user message), the order-flip-counts-as-tie rule (`outcome` and `pair_report`), and the win-rate and failure-check tallies, so the per-answer verdicts can be re-tallied and checked against the experiment reports.
- `scripts/emergent_misalignment/claude_code_cli_structured_reply_without_paid_api_fallback.py` adapts `_run_claude_code_query` from `animal-welfare-data-pipeline-emergent-misalignment-prompts/shared/api.py` (a sibling repository placed in this project as read-only input): the `claude_agent_sdk` options (no tools, one turn, hermetic settings, blanked `ANTHROPIC_API_KEY` and `ANTHROPIC_AUTH_TOKEN`, JSON schema output format) and the usage-limit classification. The `api` and `auto` backends, global state and retries were left out, so there is no path to the paid API.
