# Contributor kit paste-in prompts for control rewrite shares (draft)

Draft: the control rewrite shares do not exist yet (the final training prompt pool is not built), so no share numbers are
assigned. Replace `<SHARE_NUMBERS>` (comma separated, for example `1,2,3`) and `<SHARE_LIST_IN_WORDS>` (for example `1, 2 and 3`)
before sending. Control rewrite shares are rewrites of 400 existing prompts each, run with `--control-rewrite`; they are separate
from the spec shares 1 to 21, so a contributor who ran spec shares uses their own control rewrite share numbers here.
Each person pastes the same paragraph into a new Claude Code window each time their usage resets (about every 5 hours). Each
time it runs one share: it resumes an unfinished one if there is one, otherwise it starts the next. After each finished share it
gives a zip to send to William. A control rewrite share is run once (no second pass).

## Paste-in prompt (one share per session)

If the folder ~/emergent-misalignment-prompt-corpus-contributor-kit does not exist, clone https://github.com/wharrison2/emergent-misalignment-prompt-corpus-contributor-kit there, read its README.md and CLAUDE.md (in particular the "Control rewrite shares" sections), and set it up (a Python virtual environment and `pip install -r requirements.txt`). If it already exists, run `git pull` in it and reuse its virtual environment. My control rewrite shares are <SHARE_LIST_IN_WORDS>. Run `python run_my_shares.py --shares <SHARE_NUMBERS> --control-rewrite --status`, pick the lowest-numbered share that is not complete, and run only that share: first `python run_my_shares.py --shares <that share> --control-rewrite --dry-run`, then the same command without `--dry-run` in the background. If it stops at my usage limit, stop and tell me; I will paste this prompt again after the limit resets, and it will resume. If the run says a share has already been run (exit code 4), do not move, rename or delete anything to get around it; pick the next share that is not complete instead. If all my control rewrite shares are complete, tell me so and run nothing more. Do not add `--second-pass` or `--scenario-seed-base` (control rewrite shares use no scenario seed). Do not edit any files, do not use an API key, and do not commit or push anything. When the share prints ALL DONE, tell me the full path of the zip file it wrote under `zips_to_send_back/` so I can send it to William, and which of my control rewrite shares are still left.
