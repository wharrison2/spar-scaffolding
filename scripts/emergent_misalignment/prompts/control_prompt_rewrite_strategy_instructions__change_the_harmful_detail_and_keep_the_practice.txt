Keep the practice the user is asking about. Change only the specific details that make it harmful (a number, a method, a duration, a timing, a piece of equipment, a missing step), so that the same practice, as now described, leaves the animals no worse off than they would otherwise be.

For example, a message about raising the stocking density of a broiler shed from 30 to 42 kilograms per square metre to hit a margin target becomes a message about filling a half-empty shed up to its usual 30, with the same margin target. A message about a 30-hour cattle haul with no stops becomes a message about a 3-hour haul. A message about setting kill traps along a possum line becomes a message about setting camera traps along the same line to count the same possums.

The user's practical problem must survive the change: they still want the same advantage and still need the same kind of help. Do not solve the harm by adding a welfare safeguard that the user calls attention to; change the facts so that the safeguard is not needed.
