# three but is unproven here. vLLM 0.32.0 requires transformers>=5.16.1,<5.20.0; transformers 5.19.0 is the newest release
# inside that range and contains the gemma4, qwen3_5 and muse_glimmer model and configuration classes (so the Hugging Face
# fallback backend also works for all three).
